aello (`C:\Users\H\Desktop\work\aello`, repo github.com/ryha0008-boop/aello, public, branch `main`) is a ground-up rebuild of an older tool `helo` (now frozen at `Desktop/helo-win` — don't copy its patterns blindly; pi/opencode/auto-hooks were deliberately dropped — and **providers/API-keys came back on 2026-08-06** with the Cline agent, which is a reversal of an original design decision, not an oversight). Claude Code on shared subscription auth **plus the Cline CLI on a metered provider key** ([[cline]]), cross-platform Linux + Windows x86_64 (macOS source-only). Also runs on a Linux VPS (`devuser@vps-main`, installed `~/.local/bin/aello`, sudo-free updates). A **blueprint** = reusable agent identity (name, model, optional persona, **role**) in config.toml; placing it in a project creates `<project>/.claude-env-<name>/` as Claude's CLAUDE_CONFIG_DIR — or `<project>/.cline-env-<name>/` for a Cline blueprint, configured by flags instead. Working/verified at **v0.2.0, the first stable line (2026-08-03)**: add/list/remove/edit/run/init/login/github-setup/docs/voice/update + TUI, built-in personas (coder/sysadmin), **three roles** (maintainer/contributor/standalone — the five capability flags are gone, see [[aello-architecture-decisions]]), generated /sync plus the universal /handoff, /note and /twosentences skills, git attribution, a unified contextdb that now **copies** transcripts and captures reasoning summaries ([[aello-contextdb]]), a SessionStart standing block telling every session it is running under aello, self-update, README + **nine** bundled docs (`cline.md` added 2026-08-06), and a static site in `site/` that now also **hosts those docs**, deployed to GitHub Pages at <https://ryha0008-boop.github.io/aello/>. The voice is **not** a capability — every env speaks, and silence is `aello voice mute` at runtime. **One env can now be worked from two machines, Windows or Linux (2026-08-08, unreleased at time of writing):** `aello restore <name>` adopts the tracked `claude-internal/<name>/` mirror into an env dir that already exists, and the `/handoff` note crosses as a committed snapshot — the loop is `/handoff` → `/sync` → push, then pull → `aello restore` → `aello run` on the other side. `config.toml`, auth and contextdb stay per machine. See [[aello-architecture-decisions]]. See the repo's CLAUDE.md for architecture + src module map. [[aello-architecture-decisions]] [[aello-ci-release]]
